Natural-language geocoding. A 135M model and DuckDB run on this page; geometry comes from Overture's S3 bucket.

Heavy page ahead

This demo runs a language model and a database inside your browser.

  • The first visit downloads about 200 MB (model, place index, database engine).
  • Each search then reads another 10–170 MB of map data.
  • On a phone or tablet this can use a lot of mobile data, and the page may run out of memory and reload or crash the tab.

A desktop browser on Wi-Fi works best.
